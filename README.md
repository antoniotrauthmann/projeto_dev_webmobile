# Projeto de Desenvolvimento Web e Mobile
---
Repositório para atividade e projeto da disciplina de Desenvolvimento Web e Mobile.

##### Objetivo: Sistema de identificação de animais perdidos

##### Pontos chave do projeto:
- Cadastro de animal;
- Foto;
- Descrição de características;
- Possibilidade de abrigos informarem vagas;
- Pessoas procurarem animais para doação.
